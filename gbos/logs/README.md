# Hardware Detection Logs (`hwdetect.txt`)

This directory contains the exact hardware detection logs generated by `/gbos/hwdetect.sh` during each of the 9 boot test sessions on the **HP Laptop 15s-fr5009TU** (Intel 12th-Gen Core i3-1215U Alder Lake).

## Content Details
Each `hwdetect.txt` captures:
1. **Kernel release and build string** (`6.18.21-gbos-whl`).
2. **CPU architecture and flag support** (AVX, AVX2, BMI2, SHA_NI, GFNI, AVX_VNNI on Alder Lake i3-1215U).
3. **DMI / SMBIOS system identification** (`HP Laptop 15s-fr5xxx`, BIOS `F.28`, Board `8A20`).
4. **Unbound PCI device inventory** vs. bound drivers.
5. **Full `lsmod` table** of loaded kernel modules.
